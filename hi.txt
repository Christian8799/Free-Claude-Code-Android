## Architektur (termux-services / runit)
1. **Install FCC** → `uv tool install free-claude-code` in Termux
2. **Install termux-services** → `pkg install termux-services && termux-services enable`
3. **Setup FCC Service** → Erstellt runit-Service unter `~/.termux/services/fcc-server/`
4. **Start/Stop Server** → `sv up/down/restart ~/.termux/services/fcc-server` (persistent, überlebt Shell-Exit)

## Bekannte Probleme
- Termux:API Broadcast liefert keine Ausgabe zurück (Fire-and-forget) → `executeCommandWithOutput` nutzt Temp-Datei
- Xiaomi MIUI killt Background-Prozesse → Foreground-Service + Battery-Optimierung deaktivieren nötig
- Keine Logs in logcat (nur in Datei) → `FreeClaudeCodeApplication.logLive()` schreibt nur in File
